# Unity Games Demo

Five mini-games built with Unity 2022.3.42f1c1.

Play: https://Li1ssk.github.io/Unity-Games-Demo/

Use a desktop browser with a keyboard and mouse. Select a game on the home screen. Press Esc to pause and return home. For the courtyard puzzle, progress is saved in this browser.
